# Studio Ink

Protótipo local de atendimento e gestão para um estúdio de tatuagem, feito em HTML, CSS e JavaScript sem dependências.

## Executar

Abra `index.html` em um navegador moderno. Os projetos, conversas, pedidos de horário, favoritos e desenhos adicionados ficam no armazenamento local do navegador.

## Área do tatuador

Use **Área do tatuador** e a senha demonstrativa `studio123`. O painel inclui projetos com referência, preparação do decalque espelhado, conversas, pedidos de agenda, gerenciamento da galeria (incluindo cadastro de ilustrações e preços) e um resumo financeiro demonstrativo.

## Limites deste MVP

- Não há servidor, autenticação real nem sincronização: os dados só existem neste navegador e dispositivo.
- O assistente responde com regras locais predefinidas; não é um serviço de IA conectado.
- A área financeira não registra pagamentos nem despesas.
- A preparação do decalque permite pré-visualizar lado a lado, ajustar a largura em centímetros, espelhar, aumentar o contraste e imprimir ou baixar o PNG espelhado. Confira a escala na impressão antes de transferir o desenho.
- Não use este protótipo para guardar dados reais de clientes. Para publicar, será necessário implementar autenticação segura, armazenamento com controle de acesso e políticas de privacidade.
